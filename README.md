# CATAMP S.A.S - Ingeniería y Obra Civil

Este proyecto corresponde al desarrollo del sistema web corporativo de **CATAMP S.A.S**, una empresa con más de 6 años de experiencia en proyectos de obra civil en Bogotá y Colombia.

## Objetivos
- Crear una página web profesional y escalable.
- Documentar cada fase del desarrollo.
- Publicar el sistema en GitHub Pages y servicios de hosting para backend.

## Estructura inicial
- `requirements.md`: Documento de requerimientos funcionales y técnicos.
- `roadmap.md`: Plan de desarrollo paso a paso.
- `index.html` y `styles.css`: Primer prototipo de la landing page.
- Carpeta `docs/`: Documentación técnica.

## Tecnologías
- Frontend: HTML5, CSS3, JavaScript.
- Backend: Node.js con Express.
- Base de datos: MongoDB o PostgreSQL.
