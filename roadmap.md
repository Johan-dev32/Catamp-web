# Roadmap de Desarrollo - CATAMP S.A.S

## Fase 1: Preparación
- Crear repositorio en GitHub.
- Definir requerimientos (`requirements.md`).
- Documentar objetivos (`README.md`).
- Estructura inicial de carpetas y archivos.

## Fase 2: Frontend Básico
- Landing page con logo, slogan y menú.
- Secciones: Quiénes somos, Servicios, Portafolio, Contacto.
- Estilos básicos en `styles.css`.
- Publicación en GitHub Pages.

## Fase 3: Frontend Avanzado
- Diseño responsive.
- Galería de portafolio con imágenes.
- Formulario de contacto funcional.

## Fase 4: Backend
- Configuración de Node.js con Express.
- API para manejar formularios de contacto.
- Conexión a base de datos (MongoDB/PostgreSQL).

## Fase 5: Documentación
- Normatividad NSR-10 en carpeta `/docs`.
- Guías de instalación y despliegue.
- Manual de usuario.

## Fase 6: Optimización
- SEO básico.
- Seguridad y validaciones.
- Mejora de rendimiento.
