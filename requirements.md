# Requerimientos del Sistema Web - CATAMP S.A.S

## 1. Información General
- Empresa: CATAMP S.A.S - Ingeniería y Obra Civil
- Ubicación: Bogotá, Colombia
- Slogan: "La ingeniería que transforma tus proyectos en soluciones confiables"
- Años de experiencia: 6+
- Sectores atendidos: Residencial, Comercial, Industrial

## 2. Requerimientos Funcionales
- Página principal: Presentación, misión, visión y valores.
- Quiénes somos: Historia, experiencia, equipo.
- Servicios: Obra nueva, remodelaciones, acabados, supervisión, mantenimientos, asesoría técnica.
- Portafolio: Proyectos realizados con fotos y descripciones.
- Contacto: Teléfonos, correos, dirección y formulario.
- Documentación técnica: Normatividad NSR-10, calidad y cumplimiento.

## 3. Requerimientos Técnicos
- Frontend: HTML5, CSS3, JavaScript (React opcional).
- Backend: Python, Flask, SQLAlchemy.
- Base de datos: SQLite.
- Hosting: Render (Back-End y Front-End).
- Control de versiones: GitHub con ramas organizadas (main, dev, feature).

## 4. Extras
- SEO básico para posicionamiento en buscadores.
- Diseño responsive (adaptado a móviles).
- Documentación en carpeta `/docs`.
